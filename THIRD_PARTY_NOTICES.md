## claude-swap

Switcher adapts native Claude Code credential switching, shared-field ownership,
profile path resolution, and proper-lockfile lock ordering from
[realiti4/claude-swap](https://github.com/realiti4/claude-swap), examined at commit
`3a4e5c14873eb5b32f182d55c68da98ac8c0db45`. Its Python UI and runtime are not bundled.
